# Draft Articles

These pages are generated by:

```bash
python3 scripts/seo_system.py --write
```

They are intentionally marked:

```html
<meta name="robots" content="noindex,nofollow">
```

Use them as editable starting points. Do not publish a draft unchanged.

Manual workflow:

1. Open a draft in `drafts/`.
2. Add real testing notes, screenshots, prices, and final recommendations.
3. Move the finished article to a public article path.
4. Add internal links from `reviews.html`.
5. Run `python3 scripts/seo_system.py --write`.
